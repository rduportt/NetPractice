# NetPractice

## Description
NetPractice is a hands-on introductory project to the fundamentals of computer networking.  
The goal is to configure small-scale simulated networks so that they function correctly.  
Through 10 progressive levels, the project teaches how to assign IP addresses, understand subnet masks, set up default gateways, and interconnect devices such as routers and switches.

This project focuses on practical configuration rather than theory, although a solid understanding of TCP/IP networking is essential to succeed.
