# NetPractice

> A hands-on introduction to TCP/IP networking.

## What's inside

- IP addressing and subnet masks
- Subnetting (CIDR)
- Routing tables and default gateways
- Fixing and configuring networks across 10 levels

## Usage

There is no code to compile: the solutions are entered in the 42 NetPractice web interface.
